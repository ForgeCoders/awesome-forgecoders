## 🐍 Languages & Runtimes

### Python
*   [Python official Documentation](https://docs.python.org/3/) - The official, definitive reference for the Python programming language.
*   [Real Python](https://realpython.com/) - High-quality, in-depth tutorials and articles for Pythonistas of all levels.
*   [The Hitchhiker’s Guide to Python](https://docs.python-guide.org/) - An opinionated guide to the installation, configuration, and daily usage of Python.

### JavaScript & TypeScript
*   [MDN Web Docs - JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) - The standard, comprehensive documentation for JavaScript.
*   [JavaScript.info](https://javascript.info/) - Modern JavaScript tutorial from the basics to advanced topics, with simple but detailed explanations.
*   [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html) - Official TypeScript guide to learning how static types work on top of JavaScript.

## 🌐 Web Development & Frameworks

### React & Next.js
*   [React Documentation](https://react.dev/) - Official React docs featuring interactive play-throughs and modern hook patterns.
*   [Next.js Learn](https://nextjs.org/learn) - Step-by-step interactive course to build full-stack Next.js web applications.
*   [Epic Web / Epic React](https://www.epicweb.dev/) - Kent C. Dodds' premium tutorials on web development and React best practices.

### CSS & Animation
*   [CSS-Tricks](https://css-tricks.com/) - A repository of articles, guides, and tips on front-end web design and CSS.
*   [Framer Motion Docs](https://www.framer.com/motion/) - Documentation for the production-ready React motion library.
*   [GSAP (GreenSock) Learning](https://gsap.com/resources/) - Standard documentation and tutorials for professional, high-performance web animations.

## 🧠 AI, Machine Learning & Deep Learning

### Core Concepts & Deep Learning
*   [PyTorch Tutorials](https://pytorch.org/tutorials/) - Official guides for getting started with tensor operations, neural network construction, and model training.
*   [Fast.ai](https://www.fast.ai/) - Practical Deep Learning for Coders course, explaining state-of-the-art models with a top-down teaching method.
*   [Hugging Face Course](https://huggingface.co/course/) - An excellent free course on processing natural language, audio, and vision data using the Hugging Face ecosystem.

---

## 🎨 3D & Web3D Graphics

### Three.js & WebGL
*   [Three.js Journey](https://threejs-journey.com/) - Bruno Simon's ultimate course to learn WebGL, Three.js, shaders, and React Three Fiber.
*   [Three.js Documentation](https://threejs.org/docs/) - Official reference manual and code examples for Three.js.
*   [WebGL Fundamentals](https://webglfundamentals.org/) - WebGL from the ground up, starting with points, lines, and triangles, and scaling up to 3D.

---

## 🗄️ Databases & System Design

### Databases
*   [PostgreSQL Tutorial](https://www.postgresqltutorial.com/) - Practical, easy-to-follow PostgreSQL tutorials to master Postgres administration and development.
*   [Prisma Documentation](https://www.prisma.io/docs) - Complete guides for managing PostgreSQL, MySQL, and SQLite databases using Prisma ORM.

### System Design
*   [The System Design Primer](https://github.com/donnemartin/system-design-primer) - An open-source guide and resource list for learning how to design large-scale systems.
*   [ByteByteGo (Alex Xu)](https://bytebytego.com/) - Bite-sized, clear explanations of real-world system design architectures.

---

## 🛠️ Developer Tools & Git

*   [Pro Git Book](https://git-scm.com/book/en/v2) - The entire Pro Git book by Scott Chacon and Ben Straub, available online for free.
*   [Learn Git Branching](https://learngitbranching.js.org/) - A highly visual and interactive game to help developers master Git branching commands.
*   [Oh My Git!](https://ohmygit.org/) - An open-source game that introduces players to the internal structures and mechanics of Git.
